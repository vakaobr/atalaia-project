# GM console

Web app served by the field controller (or remotely by a site server), installable as a PWA on any phone, tablet or laptop: field map, node health, preset builder, game control, live event feed and alerts, after-action report, and the custom scenario builder.

Status: planned for phase 2, plan phase E. The REST and WebSocket API it will use is built (plan phase D, see [../README.md](../README.md#rest-api-v1)).
