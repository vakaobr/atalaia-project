# Field controller

Runs on a Raspberry Pi, a mini PC or an Android device. It:

- runs field scripts: logic that spans several props (hold-all, master and satellites, custom scenarios),
- bridges Skirmesh-RF (LoRa) to Wi-Fi,
- merges event logs and keeps the official scores,
- hosts the MQTT broker, REST and WebSocket APIs, and the GM console,
- syncs with an optional site server.
