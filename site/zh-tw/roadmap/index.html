    Field Box 的組裝、ESP32 韌體、盒子上的預設遊戲，以及附接線圖的組裝手冊。

    關卡：一個盒子跑完一場 2 小時的社團遊戲，中途不必重新啟動。韌體和它的畫面都已完成並在模擬器中執行，附接線圖的組裝手冊也已寫好。第一塊開發板（Heltec V4.3，2026 年 10 月 20 日）能開機、啟動無線電、讀取按鈕，並在自己的小螢幕上玩炸彈模式（啟動、拆除、時間用完）；在組裝好的盒子跑完 2 小時之前，關卡都維持未通過。

  3. 軟體已完成

    關卡：在 CQB 場地和戶外場地各用 5 個盒子，佔領一次都沒漏掉。加密的無線電協定、附 API 的場地控制器、USB 無線電數據機、附記分板的主辦控制台、用 NFC 卡或 QR code 加入遊戲，以及盒子韌體和控制器之間的通訊，都已完成並在模擬器、仿真器和電腦上測試過，包括整場遊戲。關卡需要無線電開發板。

    視覺化模式編輯器、模式登錄庫、載板 PCB（一塊做好的電路板，讓組裝更簡單）、翻譯、其他節點類型的組裝指南。已在軟體中完成的：視覺化模式編輯器，這是模擬器裡的一個頁面，用積木組出一個模式（隊伍按住按鈕時會發生什麼、計時器、分數、畫面和音效、GM 可以調整的設定，以及場地控制器跨盒子的邏輯）；它會隨著你的操作寫出模式的 Lua 腳本和清單，有葡萄牙文和英文，而且能離線使用。它也有地圖上的據點、GM 指令、多個角色和模式自己畫面的積木；三個範例通過和手寫模式相同的測試，按一個按鈕就能立刻在模擬器中試玩這個模式。模式以經簽署的套件傳遞（一個封存檔，像韌體版本一樣簽署）；場地控制器只用自己信任的金鑰安裝它們，並顯示每個套件是誰簽署的、專案是否審閱過。編輯器也能自己產生模式的套件，和打包工具做出來的封存檔完全相同，並顯示模式金鑰會簽署什麼，以及簽署用的指令；簽署仍在作者自己的電腦上離線進行。每次修改都會跑一組逃脫嘗試測試，已經堵住兩個讓腳本超過時間限制的方法。在 GM 控制台中，缺少遊戲模式的盒子會收到提議：傳送缺少的模式會再次邀請它，它就透過場地 Wi-Fi 從場地控制器取得經簽署的套件，只在兩場遊戲之間進行，遊戲會等它；盒子用韌體內建的金鑰檢查並保存套件（已在電腦上測試，還沒在真實的盒子上試過）。現在也能在 GM 控制台中用積木組成劇本：盒子、任務目標和誰看得到它們、什麼時候開放、什麼條件完成以及完成後給什麼，用滑鼠、觸控或鍵盤操作，有葡萄牙文和英文，手機上也能用；場地控制器會像手寫的一樣檢查並安裝它們。讓作者分享模式的登錄庫已準備好作為範本：附經簽署模式的 pull request 會自動檢查（它的簽章、原始碼是否就是被簽署的內容、授權條款、在模擬器中的測試），專案審閱過的模式會得到已驗證徽章，也就是專案自己的簽章，有了它模式才能送到盒子上。如何提交模式、審閱檢查清單、金鑰和管理規則都已寫成文件。Atalaia 現在也有德文和台灣使用的繁體中文（本頁、GM 控制台、模式編輯器、App、Field Box 的畫面、內建模式和場地伺服器的頁面），兩者都由 AI 模型起草，還沒有經過說這些語言的玩家審閱：如果你用德文或中文玩，請幫我們審閱；其他語言的翻譯從 docs/translations（英文）開始。下一步：從範本建立登錄庫；審閱德文和中文；在第一批盒子組裝好之後做載板 PCB。
