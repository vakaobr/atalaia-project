# Target addon

Steel or polycarbonate plate with a piezo sensor and a small MCU (RP2040 or ATtiny) for hit detection, plus a WS2812
ring. Connects to a box through the M12 addon port. The hardware of the Target Windows mode (built in software).

[BUILD.md](BUILD.md) lists what is decided and what is not: the addon's MCU firmware, the port's protocol and pin
order, the bus voltage and the interrupt line's GPIO are still open (phase 4 plan phase HW2), so it is **not buildable
yet**.

Status: design phase.
