# Hardware

Reference builds made from off-the-shelf parts, with no custom PCB required. A carrier PCB will follow later.

| Build | Purpose | Approx. cost |
| --- | --- | --- |
| [Field Box](field-box/) | Main prop: domination, bomb, codes, tags | €70–110 |
| [Satellite](satellite/) | Small secondary point or beacon | €30–40 |
| [I/O pod](io-pod/) | Gives an Android prop LoRa, big buttons, LEDs and a siren | about €35 |
| [Target addon](target-addon/) | Hit-scoring target for any box | €20–30 |

Costs are approximate hobby-market prices, not quotes.

Licence: CERN-OHL-S-2.0. Improved designs you distribute must stay open.

Each build folder will hold: a bill of materials, wiring diagram, enclosure files (STL/STEP), assembly guide and photos.

## Safety

Bright colours, "GAME PROP" labels, nothing resembling a real explosive device. Use protected Li-ion cells with a BMS and charge under supervision.
